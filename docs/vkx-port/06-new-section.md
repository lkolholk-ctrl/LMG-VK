# Раздел New: layout'ы каталога VK X

Перенос отображения блоков `catalog.getAudioAuto` из VK X. Экран —
`app/src/main/kotlin/com/lmg/vk/ui/screens/NewScreen.kt`, данные приходят
через `HomeViewModel` → `HomeBlock` / `HomeItem` (`BackendModels.kt`).

## Что определяет вид блока

Ключ — `layoutName` в `HomeBlock`. VK присылает его вместе с блоком, и это
единственный признак, по которому решается форма отображения: `type` слишком
грубый (`banner`, `charts`, …), а по составу элементов форму не угадать.

Имена ниже **найдены в исходниках VK X** (jadx-вывод, поиск строковых
литералов), а не придуманы. Итого в клиенте VK X встречается 21 каталожное
имя; ниже отмечено, что перенесено.

## Батч 1 — что сделано

Три новых компонента, все в стиле экрана (`AlbumArtImage`, `LiquidTheme.colors`,
`AppFontFamily`, компактный режим множителями):

- `NewLargeCard` — обложка 4:3 (248×184, компакт 190×140). Смысл не в размере:
  широкая карточка вмещает в экран меньше элементов, и именно этим VK выделяет
  «большие» блоки среди обычных каруселей. Номер чарта рисуется, если
  `layoutName` начинается на `music_chart`.
- `NewExtendedCard` — квадратная обложка, подзаголовок в две строки: у VK это
  блок с описанием, одной строки не хватает.
- `NewDoubleGrid` + `NewGridTile` — горизонтальная прокрутка, но элементы идут
  парами по вертикали (`chunked(2)`), порядок читается слева-вниз-вправо, как
  в оригинале. Плитка — обложка слева, подписи справа.

Наборы имён вынесены в `NEW_LARGE_SLIDER_LAYOUTS` и `NEW_GRID_LAYOUTS`;
пересечений между всеми наборами нет, поэтому каждый layout попадает ровно в
одну ветвь `when`. Подписи в шторке «показать все» дополнены в
`newLayoutLabel` (чарт / эксклюзив / рекомендации / сетка / жанры).

## Что осталось (батч 2)

Баннерное семейство (`podcast_banners_slider`, `smart_banner`) ложится в
существующий hero-путь почти без нового кода. Два пункта требуют решений:

- `close_catalog_banner` — нужен крестик и запоминание закрытия
  (`SharedPreferences` по id блока), иначе баннер вернётся после перезапуска;
- `subsection_tabs` — структурный: это не карточки, а переключатель
  подразделов внутри блока, каждому табу соответствует своя выдача.

Связано: [[vkx-port-source]] — источник реверса, `01-music.md` — сами методы
каталога.
